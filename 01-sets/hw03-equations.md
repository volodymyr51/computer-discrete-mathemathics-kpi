# Домашнє завдання 3. Множини: рівняння

**Тема:** Теорія множин
**Максимальна оцінка:** до 3 балів

Рівняння в алгебрі множин розв'язуються приведенням до вигляду
`M X ∪ N = ∅`, звідки (за тотожністю 21 з довідки в `README.md`) розв'язком є
`N ⊆ X ⊆ M̄`. Використовуйте тотожності з довідки (особливо 10, 12–15, 21–22)
для перетворення рівняння до такого вигляду.

**Приклад.** Розв'язати рівняння `X ∪ C = D`, `C ⊆ D`.

За тотожністю 22: `(X ∪ C) ∸ D = ∅`. За тотожністю 15 прибираємо `∸`:
`D̄ ∩ (X ∪ C) ∪ D ∩ (X ∪ C)‾ = ∅` → після розкриття дужок за теоремою
де Моргана і використання умови `C ⊆ D` рівняння зводиться до
`D̄ ∪ X ∩ D̄ = ∅`, звідки `D ⊆ X ⊆ D` — тобто `X = D`.

## Завдання

Розв'язати рівняння (там, де вказана додаткова умова — врахувати її):

1. `A ∸ B = B ∸ X`
2. `A ∪ X = X \ B`
3. `C \ B = (A ∪ B) \ X`, `A ⊆ C`
4. `X \ A = C \ X`
5. `A ∸ C = C \ A`, `A ⊆ C`
6. `A \ (X \ C) = A ∪ C`
7. `(A \ X) \ C = A ∪ C`
8. `A ∸ X = C \ X`
9. `(A ∩ X) ∩ (C \ X) = A ∩ C`
