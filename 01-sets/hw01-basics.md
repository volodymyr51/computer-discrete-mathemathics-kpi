# Домашнє завдання 1. Множини: базові поняття, рівність, включення

**Тема:** Теорія множин
**Максимальна оцінка:** до 3 балів

## Завдання

### 1. Які з наведених нижче співвідношень неправильні й чому?

1. `x ∈ {2, a, x}`
2. `3 ∈ {1, {2, 3}, 4}`
3. `x ∈ {1, sin x}`
4. `{x, y} ∈ {a, {x, y}, b}`

### 2. Чи рівні між собою множини A і B? Якщо ні — чому?

1. `A = {2, 5, 4}`, `B = {5, 4, 2}`
2. `A = {1, 2, 4, 2}`, `B = {1, 2, 4}`
3. `A = {2, 4, 5}`, `B = {2, 4, 3}`
4. `A = {1, {2, 5}, 6}`, `B = {1, {5, 2}, 6}`
5. `A = {1, {2, 5}, 6}`, `B = {1, 2, 5, 6}`

### 3. Чи пов'язані множини A і B відношенням включення? Якщо так — яка з них підмножина іншої?

1. `A = {a, b, d}`, `B = {a, b, c, d}`
2. `A = {a, c, d, e}`, `B = {a, e, c}`
3. `A = {c, d, e}`, `B = {c, a}`
4. `A = {1, {2, 3}}`, `B = {1, 2, 3}`
5. `A = {1, {2, {3}}}`, `B = {1, 4, {2, {3}}}`

### 4. У яких відношеннях перебувають між собою три множини?

`A = {1, 3}`; `B` — множина непарних додатних чисел; `C` — множина розв'язків рівняння `x² − 4x + 3 = 0`.

### 5. Свята та вихідні

Утворіть множину святкових (неробочих) днів поточного року. Чи перетинається ця множина з множиною вихідних днів (субот і неділь) цього ж року? Якщо так — випишіть елементи перетину (дати, коли святковий день випадає на суботу чи неділю).

## Додаткові задачі (не обов'язкові, підвищена складність)

**Д1.** У множині з `n` елементів вибрано `2ⁿ⁻¹` підмножин, кожні три з яких мають спільний елемент. Довести, що всі ці підмножини мають спільний елемент.

**Д2.** Дано 1991 множину, кожна з яких складається з 45 елементів, причому об'єднання будь-яких двох з них містить рівно 89 елементів. Скільки елементів містить об'єднання всіх множин?
