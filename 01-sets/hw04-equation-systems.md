# Домашнє завдання 4. Множини: системи рівнянь

**Тема:** Теорія множин
**Максимальна оцінка:** до 3 балів

## Метод розв'язання

Системи рівнянь з множинами розв'язуються за тим самим принципом, що й окремі
рівняння (див. ДЗ 3). Кожне рівняння системи розв'язується окремо, після чого
результати об'єднуються.

Наприклад, нехай розв'язок першого рівняння — `A ⊆ X ⊆ B`, а розв'язок
другого — `C ⊆ X ⊆ D`. Тоді розв'язком системи буде `A ∪ C ⊆ X ⊆ B ∩ D`.

**Важливо:** всі *додаткові умови*, що задані в системі, стосуються *обох*
рівнянь. Так само й додаткові співвідношення, що виникають *у процесі*
розв'язання одного з рівнянь (наприклад, умова існування розв'язку), теж
стосуються *обох* рівнянь системи, навіть якщо виникли лише під час
розв'язання одного з них.

## Завдання

Розв'яжіть наступні системи рівнянь відносно `X` (кожна система складена з
двох рівнянь ДЗ 3 — за потреби перевикористайте проміжні результати звідти):

1. `{ A ∸ B = B ∸ X;  X \ A = C \ X }`
2. `{ A ∪ X = X \ B;  A \ (X \ C) = A ∪ C }`
3. `{ C \ B = (A ∪ B) \ X, A ⊆ C;  (A \ X) \ C = A ∪ C }`
4. `{ A ∸ C = C \ A, A ⊆ C;  A ∸ X = C \ X }`
5. `{ X \ A = C \ X;  (A ∩ X) ∩ (C \ X) = A ∩ C }`

Для кожної системи вкажіть, за якої додаткової умови на `A`, `B`, `C`
(якщо вона потрібна) розв'язок існує.
