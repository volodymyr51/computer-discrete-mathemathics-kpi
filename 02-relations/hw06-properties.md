# Домашнє завдання 6. Відношення: властивості

**Тема:** Відношення
**Максимальна оцінка:** до 3 балів

## Завдання

### 1. Визначити властивості відношень на множині {1, 2, 3, 4, 5}

Для кожного з відношень нижче визначте, які з властивостей —
рефлексивність, симетричність, антисиметричність, транзитивність — воно має.

1. `R1: a R1 b ↔ |a − b| = 1`
2. `R2: a R2 b ↔ 0 < a − b < 3`
3. `R3: a R3 b ↔ a + b — парне число`
4. `R4: a R4 b ↔ a ділить b²`
5. `R5: a R5 b ↔ НСД(a, b) = 1`

### 2. Встановити властивості відношень `R ⊆ A × B`

`A = {1, 2, ..., 8}`, `B = {1, 2, ..., 15}`, `(a, b) ∈ R`. Для кожного
відношення визначте його властивості (рефлексивність, симетричність,
антисиметричність, транзитивність — там, де це має сенс для відношення між
різними множинами `A` і `B`), а також з'ясуйте, чи є відношення
функціональним (тобто чи кожному `a` відповідає не більше одного `b`).

1. `a < b`
2. `a > b`
3. `a + b ділиться на 3`
4. `a − b < 3`
5. `a — дільник b`
6. `b − a > 6`
