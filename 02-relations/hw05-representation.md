# Домашнє завдання 5. Відношення: способи задання, область визначення і значень

**Тема:** Відношення
**Максимальна оцінка:** до 3 балів

## Завдання

### 1. Записати відношення трьома способами

Для кожного відношення нижче запишіть його:
— переліченням упорядкованих пар елементів;
— у вигляді матриці;
— у вигляді (дводольного) графа.

Знайдіть область визначення і область значень кожного відношення.

1. `R = {<x, y> | |x − y| ≤ 1}`, `X = Y = {1, 2, 3, 4}`
2. `R = {<x, y> | x \ y = ∅}`, `X = Y = {A, B, C, D}`, де
   `A = {0, 1, 2, 3}`, `B = {0, 2}`, `C = {1, 3, 4}`, `D = {1, 2, 3}`

### 2. Записати кожне бінарне відношення трьома способами

Для кожного відношення `R ⊆ A × B` нижче:
— запишіть його переліком, матрицею та дводольним графом (вершини у два
стовпчики: зліва — область визначення, справа — область значень);
— знайдіть область визначення та область значень.

1. `A = {5, 6, 7, 8, 9, 10}`, `B = {1, 2, 3, 4, 5}`, `R = {(a, b) | a − b > 6}`
2. `A = {−2, −1, 0, 1, 2}`, `B = {−1, 0, 1}`, `R = {(a, b) | a² > b²}`
3. `A = {1, 2, 3, 4, 5}`, `B = {2, 3, 4, 5, 6}`, `R = {(a, b) | a > b}`
4. `A = {2, 3, 4, 5}`, `B = {4, 5, 6, 7, 8, 9}`, `R = {(a, b) | a — дільник b}`
5. `A = {3, 4, 5, 6, 7}`, `B = {1, 2, 3}`, `R = {(a, b) | a − b < 3}`
6. `A = {3, 4, 5, 6}`, `B = {2, 3, 4, 5}`, `R = {(a, b) | a² − b² ≤ 0}`
7. `A = {1, 2, 3, 4, 5}`, `B = {1, 2, 3, 4}`, `R = {(a, b) | a ≡ b (mod 3)}`
   (тобто `a` і `b` дають однакову остачу при діленні на 3)
