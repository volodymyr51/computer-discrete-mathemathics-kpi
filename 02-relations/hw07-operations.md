# Домашнє завдання 7. Відношення: операції

**Тема:** Відношення
**Максимальна оцінка:** до 3 балів

## Завдання

### 1. Доповнення, об'єднання, композиція

Для кожної пари відношень `R1` та `R2` (обидва на `A = B`, як вказано)
знайдіть:
1) доповнення кожного з відношень (`R1‾` і `R2‾` відносно `A × B`);
2) об'єднання `R1 ∪ R2`;
3) композицію `R1 ∘ R2`.

- а) `R1 = {<1,2>, <2,1>, <2,3>, <1,3>}`, `R2 = {<1,2>, <2,3>, <1,3>, <4,1>, <2,4>}`, `A = B = {1, 2, 3, 4}`
- б) `R1 = {<2,1>, <1,3>, <3,4>, <4,6>, <6,5>}`, `R2 = {<5,4>, <4,2>, <6,2>}`, `A = B = {1, 2, 3, 4, 5, 6}`
- в) `R1 = {<2,1>, <2,4>, <4,3>, <6,4>, <5,6>}`, `R2 = {<1,4>, <3,1>, <3,6>, <6,3>, <4,5>}`, `A = B = {1, 2, 3, 4, 5, 6}`
- г) `R1 = {<1,2>, <2,3>, <3,1>, <3,4>, <1,5>, <5,4>}`, `R2 = {<2,1>, <1,4>, <4,1>, <5,5>, <4,3>}`, `A = B = {1, 2, 3, 4, 5}`

### 2. Повний набір операцій

Над відношеннями `ρ1` і `ρ2` виконайте операції
`ρ1 ∪ ρ2`, `ρ1 ∩ ρ2`, `ρ1 \ ρ2`, `ρ2 \ ρ1`, `ρ1 ∸ ρ2`, `ρ1 ∘ ρ2`, `ρ2 ∘ ρ1`,
`ρ1⁻¹`, `(ρ1 ∪ ρ2)⁻¹`:

`ρ1 = {<1,2>, <2,3>, <1,4>, <3,5>}`,
`ρ2 = {<2,4>, <3,6>, <4,3>, <4,2>, <3,5>}`.

### 3. Довести

Довести, що для довільних відношень `A`, `B`, `C` композиція дистрибутивна
відносно об'єднання зліва:

`(A ∪ B) ∘ C = (A ∘ C) ∪ (B ∘ C)`.

### 4. Дослідити

Чи є рефлексивними відношення `ρ1 ∪ ρ2`, `ρ1 ∩ ρ2`, `ρ1⁻¹`, якщо
рефлексивні відношення `ρ1` і `ρ2`? Обґрунтуйте відповідь.
