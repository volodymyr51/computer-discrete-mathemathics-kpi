# Домашнє завдання 8. Функції: ін'єкція, сюр'єкція, бієкція

**Тема:** Функції
**Максимальна оцінка:** до 3 балів

## Завдання

### 1. Властивості відповідностей

Між множинами `A = {a, b, c, d, e}` і `B = {1, 2, 3, 4, 5}` задані
відповідності `Ri`. Визначити, які з них усюди визначені, функціональні,
ін'єктивні, сюр'єктивні, бієктивні.

1. `R1 = {(a,2), (a,5), (b,1), (b,5), (c,2), (d,3), (d,5)}`
2. `R2 = {(a,3), (b,2), (c,3), (e,3)}`
3. `R3 = {(a,2), (b,3), (c,4), (d,1), (e,5)}`
4. `R4 = {(a,2), (a,3), (b,1), (c,4), (c,5), (d,1), (e,2), (e,4)}`
5. `R5 = {(a,4), (b,3), (c,5), (d,2), (e,1)}`

### 2. Чи є функція `f` ін'єктивною, сюр'єктивною чи бієктивною?

1. `f: x ↦ sin x`, `x ∈ ℝ`, `f(x) ∈ [−1; 1]`
2. `f: x ↦ sin x`, `x ∈ [−π/2, π/2]`, `f(x) ∈ ℝ`
3. `f: x ↦ sin x`, `x ∈ [−π/2, π/2]`, `f(x) ∈ [−1; 1]`
4. `f: n ↦ (−1)ⁿ · n`, `n ∈ ℕ`, `f(n) ∈ ℤ`
5. `f: x ↦ x + |x|`, `x ∈ ℝ`, `f(x) ∈ ℝ`
6. `f: x ↦ ln(|x| + 1)`, `x ∈ ℝ`, `f(x) ∈ ℝ`

### 3. Раціональна функція

Нехай `f(x) = (2x − 1) / (x + 2)`.

1. Знайдіть область визначення функції `f`.
2. Доведіть, що `f` ін'єктивна на своїй області визначення.
3. Знайдіть обернену функцію `f⁻¹` та вкажіть її область визначення й область
   значень.
4. Чи є `f` сюр'єктивною як відображення `f: D(f) → ℝ`? А як відображення
   `f: D(f) → E(f)`?
